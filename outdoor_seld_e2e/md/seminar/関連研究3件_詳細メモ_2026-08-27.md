## 1. PAWS（2018）

**正式名**: PAWS: A Wearable Acoustic System for Pedestrian Safety
**出典**: IEEE IPSN 2018, Columbia University ICSL
[IEEE](https://ieeexplore.ieee.org/document/8366992/) ／ [公式ページ](https://icsl.ee.columbia.edu/paws/)

### 何をしたか

ヘッドセットに埋め込んだマイクアレイで、**車のクラクション・エンジン音・タイヤ音から車を検出し、
方向を出して歩行者に警告する**システム。

> "detect and locate cars from their **honks, engine and tire noises**, and warn pedestrians
> of imminent dangers of approaching cars"

### 構成（3段階）

```
① ヘッドセットのマイクアレイ
② 組み込みフロントエンド … 信号処理・特徴抽出
③ スマートフォンアプリ   … 機械学習で検出・定位
```

### 方向の出し方

**ITD（両耳間時間差）と ILD（両耳間レベル差）**。専用ASICが **PCC**
（polarity coincidence correlation）で時間差を**ナノワット級の消費電力**で計算する。
**連続の方位角を出す仕組みではなく、機械学習による分類。**

### 種類の判別

**NBIP**（Non-Uniform Binned Integral Periodogram）という自作の周波数特徴。
MFCCより良いと主張。スペクトルのどこを強調するかを設計者が調整できる。

### 性能

| | |
| --- | --- |
| 検出距離 | **80m まで**（"up to 80 meters"） |
| 精度 | **precision 99% / recall 97%**（"up to 99% precision and 97% recall"） |
| リードタイム | **時速48km（30mph）の車に約6秒前**（"about 6s in advance for a 30mph car"） |

### 対象ユーザー ← ここが本研究との最大の差

> "acts as a **second pair of ears** in situations where the user's sense of hearing is
> greatly diminished, such as when the user is **taking a phone call or listening to music**"

**通話中・音楽再生中で一時的に聞こえにくい健聴者**が対象。**難聴者は想定されていない。**

### 未確認（聞かれたら正直に引く）

- **マイクの本数**（情報源によって4本とも5本とも書かれている）
- **方向の分解能**（何区分に分けているか、角度誤差）
- **複数台を扱えるか**（サーベイでは「論文が自認」とあるが、IEEE本文が有料で未確認）

## 2. Chin et al.（2023）

**正式名**: A Wearable Assistant Device for the Hearing Impaired to Recognize
Emergency Vehicle Sirens with Edge Computing
**出典**: *Sensors* 2023, 23(17), 7454. [DOI 10.3390/s23177454](https://www.mdpi.com/1424-8220/23/17/7454)
（2023年8月27日公開）

### 何をしたか

**難聴者向け**に、道路上の警告音を**手元のマイコンだけで**判別し、**振動と画面**で伝える装置。

### ハードウェア

**Arduino Nano 33 BLE Sense**（親指サイズの開発ボード）。クラウドに送らず**手元で計算**する
（エッジ計算）ので、電波がなくても動く。

### モデル

**EfficientNet ベース・ファジィランクのアンサンブル**。

### 7クラスの中身 ← ここが重要

| 種別 | クラス |
| --- | --- |
| **感情音声 4つ** | neutral / anger / fear / happy |
| **警告音 3つ** | car horn（クラクション）/ siren / ambulance siren |

**「7つの音」のうち4つは人の感情音声で、危険音は3つだけ。**
データは **CREMA-D**（感情音声のデータセット）＋
**Large-Scale Audio dataset of emergency vehicle sirens on the road**、計 **8,756ファイル**。

### 性能 ← 数字が2つあるので注意

| | accuracy | precision | sensitivity | specificity |
| --- | --- | --- | --- | --- |
| **モデル単体** | **97.05%** | 97.79% | 96.8% | 97.04% |
| **エッジ実装** | **95.22%** | 93.19% | 95.27% | 95.09% |

**どちらを言うかで数字が変わる。**「モデルは97%、実機に載せると95%」と言えば正確。

### 出力

> "start the **vibrator** and send a message to the **OLED**"

クラクション・サイレン・救急車サイレンと判断したとき、**振動子を回して小さな画面に文字を出す**。

### 本研究との差

- **方向がない**（分類モデルなので、そもそも方向を出す仕組みがない）
- **同時に1つの音**（分類タスク）
- **危険音は3クラスだけ**（本研究は8クラス）

## 3. 6DoF SELD（2024）

**正式名**: 6DoF SELD: Sound Event Localization and Detection Using Microphones and
Motion Tracking Sensors on self-motioning human
**出典**: Sony, ICASSP 2024. [arXiv:2403.01670](https://arxiv.org/abs/2403.01670)

### 何をしたか

**歩いている人に装着したマイクでSELDをやる**。問題は「**自分が動くと音の来る方向が見かけ上ずれる**」
こと。それを**動きのセンサの信号で打ち消す**手法。

### ハードウェア

| | |
| --- | --- |
| マイク | **Hosiden KUB4225 を18ch**、ヘッドホン型（左右のイヤーパッドに外周8ch＋中心1ch）。48kHz/16bit |
| 実験で使用 | **ch 0 / 4 / 8 / 12 の4本**（左右イヤーパッドの前後） |
| 動きの計測 | **HTC Vive Tracker (2018) + SteamVR Base Station 2.0** |

**アンビソニックス（FOA）には変換していない。生のマルチチャンネル信号のまま。**
速度・角速度は、トラッカーの位置・姿勢を **Savitzky-Golay で平滑化しながら1次微分**して得る。

### データ

| | |
| --- | --- |
| 環境 | **可変残響室**（T60 = 0.12 / 0.30 / 0.41秒）＝**屋内** |
| 規模 | **20.1時間・12クラス** |
| 動き条件 | 静止 / 3DoF回転 / **6DoF歩行** の3種 |

### 手法

**Causal-SELDNet + MMTM**（Multimodal Transfer Module）。
MMTMは音響特徴とセンサ特徴から**joint embedding**を作り、そこから**励起重み**を生成して
**音響特徴を動きの状態で変調**する。

特徴量は **4ch振幅スペクトログラム ＋ 3ch SALSA-Lite**。

### 結果

| 指標 | ベースライン（音のみ） | 提案（センサ併用） |
| --- | --- | --- |
| ER≤20° | 0.55 | **0.51** |
| F≤20° | 49.1 | **54.1** |
| LE_CD | 21.6° | **20.0°** |
| LR_CD | 85.2% | **86.1%** |

> "the (D) and (E), which use **velocity and angular velocity extracted from head tracking
> sensors** as input features, perform better on **all metrics** than (B) and (C),
> which only use audio modality."

**F値が49.1→54.1%。実録での装着SELDはこの水準。**（本研究の合成データでの値とは
母集団も条件も違うので**並べて比べないこと**）

### 本研究との差

- **屋外ではない**（可変残響室）
- **危険度の判断がない**（SELDの手法研究であって、通知システムではない）
- **事前学習済みモデルが配られていない**（手法の論文）
- **規模が20.1時間・12クラス**（PSELDNetsは1,167時間・170クラス）
- **マイクの配置が別物**（左右の耳に付けた4点 vs FOA）

## 想定質問と答え

**「PAWSでいいのでは？」**
> PAWSは**通話や音楽で一時的に聞こえにくい健聴者**向けです。難聴者は想定されていません。
> 扱うのも**車だけ**で、サイレンや踏切は入りません。

**「PAWSの方向はどれくらい粗いのか」**
> **マイク間の時間差と音量差から機械学習で分類**する方式で、**連続の角度を出す仕組みではありません**。
> **何区分に分けているかは、原論文が有料で確認できていません。**

**「Chinらの研究は7つも聞き分けているのでは？」**
> **7つのうち4つは人の感情音声**です（neutral / anger / fear / happy）。
> **危険音はクラクション・サイレン・救急車サイレンの3つだけ**です。本研究は8クラスを扱います。

**「Chinらの精度は？」**
> **モデル単体で97.05%、実機（Arduino）に載せると95.22%**です。
> ただし**方向は出ません**。分類モデルなので、そもそも方向を出す仕組みがありません。

**「6DoF SELDを基盤にすればいいのでは？」**
> **手法の論文で、事前学習済みモデルが配られていません。**学習データも
> **室内の可変残響室で20.1時間・12クラス**です。PSELDNetsは1,167時間・170クラスなので
> 転移の土台としては桁が違います。**マイクの配置も左右の耳に付けた4点**で、FOAとは別物です。

**「6DoF SELDはどれくらいの性能なのか」**
> **F値が49.1%から54.1%**に上がっています。方向誤差は**20度**です。
> ただし**実録・屋内**の数字なので、本研究の合成データの値とは**並べて比べられません**。

**「自己移動の補正はどうやっているのか」**
> **VRのトラッカー**（HTC Vive）で位置と姿勢を測り、それを微分して**速度と角速度**にします。
> それを**MMTM**という仕組みで音響特徴に混ぜて、動きの状態で特徴を変調します。
> なお**部屋にベースステーションを設置する必要がある**ので、公道ではそのまま使えません。
