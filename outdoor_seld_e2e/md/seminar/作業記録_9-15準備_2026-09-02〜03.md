## 2. 装着位置の議論 — 結論「胸のまま」

本人の問い「ヘルメット装着はどうか。そもそもなぜ胸だったか」から始まった検討。

### 胸装着の根拠（既存記録の再確認）

1. 実機像が首元の振動デバイス（`通知設計の調査と確定_2026-07-16.md`:82）。胸はそこに最も近い
2. 肩は左右非対称な体遮蔽が方位に系統バイアス、手持ちは向き変動と接触音で却下済み
   （`実録再設計レビュー_Claude監査_2026-08-14.md`:78-84）
3. 傾き±20°までは性能ほぼ不変と2026-07-23に実測（48/48正解・方位誤差最悪+4°）
4. 体遮蔽の絶対量は三脚/胸のA/B（代表10試行）で別途測る設計がある

### ヘルメットを採らない決定的な理由

方位校正は「セッション頭にベル4方位を鳴らし、**マイク正面と体正面のズレを1回測って
一定とみなし全テイクに適用**」する方式。胸は体幹固定なのでズレが一定。**ヘルメットは
首が回るたびズレが変わるので1回の校正では直せない**。記録紙の正解は体基準の象限
（F/B/L/R）なので、振り向くと紙とマイクで象限が食い違い採点が壊れる。

### 実機の装着位置（本人の問い「実用では胸も無理では」への答え）

- 実機像は**ネックバンド型**（ペンダントではない）。既に図がある＝`図_振動デバイス完成イメージ_2026-08-27.svg`
- マイクは**バンド前面中央に埋め込む**。振動子と同じ剛体に載るので「マイクの右＝振動子の右」
  になり、頭部の向きセンサーが不要になる
- 胸ハーネスは**ネックバンド前面の代用**。鎖骨と胸骨の差は縦10〜15cmで、実機の方が
  体遮蔽は軽い ＝ **胸での測定は悲観側＝安全側**
- 無料でできる改善2つ: ①ハーネスのストラップを一番上まで詰める
  ②既に計画にある「リュックのショルダーストラップ前面上部」は鎖骨の高さなので、
  目立たなさだけでなく**実機位置の再現としても正確**

### 自作4chアレイを使わない理由（卒論では）

較正済みでないアレイを挟むと、方位の誤差が「モデルのせい」か「マイクのせい」か
区別できなくなる。加えて4ch同期96kHz録音の機械が別に5〜8万円要る。**修士でやるべきで、
そのときH3-VRが答え合わせ用の基準器になる**（→ 購入論拠4をこの言い方に差し替えた）。

## 3. H3-VR の実仕様（公式で裏取り済み）

出典 = ZOOM公式クイックガイド `J_H3-VR_QuickGuide.pdf` の仕様表

| 項目 | 値 |
| --- | --- |
| 外形寸法 | 76(W) × 78(D) × **123(H)** mm |
| 質量 | **120 g（本体のみ）** ＋単三2本 → 実装備 約166〜175g |
| 内蔵マイク | **マッチング済**単一指向性コンデンサマイク × 4 |
| 位置センサー | 6軸（3軸ジャイロ・3軸加速度） |
| 録音モード | FuMa / **AmbiX** / Ambisonics A / ステレオ |
| 電源 | 単三×2（48kHz/24bitで約11.5時間） |
| 同梱 | ウインドスクリーン・**三脚マウント**（thomann仕様表 "Foam Windscreen, Tripod Mount"） |

### ⚠️ マイクポジションの正確な挙動（前回の説明を訂正）

**自動なのは4つの離散的な向きの判別だけ**: Upright / Upside Down / Endfire / Endfire Invert。
「自動」にすると録音開始時の向きから選ばれる。**その4つからの傾きは補正されない。**

> 「の傾きは位置センサーで検知され、ホーム画面に表示されます。
> 水準器の表示がセンターに合うように、の角度を調節してください。」

つまり傾きは**水準器として表示されるだけ**で、角度合わせは人間の作業。

**運用への影響**: 胸に着けると画面が見えない。**装着後に協力者か鏡で水準器を確認する行を
記録紙の冒頭儀式に追加すること**（未実施）。守るのは2つだけ ①4つの向きのどれかに
はっきり合わせる（45°のような中間にしない）②その向きの中で水平を保つ。
±20°までは実測で性能ほぼ不変なので、実害は小さい。

### 他機種の検討（結論: H3-VR一択は不変）

向きの問題は**アンビソニックス方式そのものに由来**する（A→B変換の式がマイクの軸基準）。
上位機（Sennheiser Ambeo・RØDE NT-SF1、6万円〜）は**そもそも向きの検出センサーを持たず**、
変換ソフト側で人間が指定する。6軸センサーと水準器があるH3-VRの方が親切。

### チェストハーネスへの取り付け（要・変換アダプター）

H3-VRは1/4インチネジ規格につながるが、GoProチェストハーネスは3又フィンガー。
間に「**GoProマウント（フィンガー）側 ＋ 1/4インチ オスネジ側**」の変換アダプターが要る。

| 商品 | 価格 |
| --- | --- |
| エツミ GoPro対応1/4変換アルミアダプター E-2489 | 2,695円 |
| レックマウント GP-CN-KD（アルミ46g） | 3,080円 |

- ⚠️ **どちらの商品ページにもオス/メスの明記がない。** 逆向き（GoProカメラを三脚に付ける=
  1/4がメス穴）の製品が大量に混在するので、**商品写真でネジが突起になっていることを確認**
- ⚠️ 「本体底面に直接ネジ穴がある」のか「同梱の三脚マウント経由で1/4になる」のかは
  公式資料で確認できなかった。**購入時に現物か販売店で確認すること**
- 💰 **見積りの穴**: 小物6,000円に「チェストハーネス2,000円」しかなく、アダプター代が
  入っていない。実費は ハーネス2,000＋アダプター2,700〜3,100円

学習データは**理想FOA**（`v9設計書_改訂第2版_2026-07-16.md`:128）。理想FOAは全周波数で
方向が完璧だが、**実際の四面体マイクは4〜9kHz以上で方向精度が落ちる**（マイク間隔が
半波長を超える帯域。文献では3.4cm間隔で5kHz）。

`合成が理想的すぎる問題_回答整理_2026-08-25.md` の劣化要因リストには「マイクは完全静止・
無回転」しかなく、**高域の方向精度の項目がない**。実録で自転車ベルやクラクション
（高域中心）の方向だけ悪かったときに説明できない。**先に書いておけば「予想していた」と言える。**

⚠️ 副作用の疑い: **方位校正にベルを使っている**が、ベルはまさにこの影響を受ける帯域。
校正の精度自体が甘くなっていないか要確認。手拍子（時刻同期で既に鳴らしている）は
広帯域なので校正に向いている可能性。**これは推測。未検証。**

fold30は**調整用**で、卒論に載せる確定評価（fold20）とは別枠。スライドに出すときは
「調整用データの値・確定評価ではない・中間発表とは測り方が違う」を必ず添える。

### 指標の定義（`scripts/_notify_v42_eval.py` の `score()`）

- **至近到達** = 危険イベントのうち何らかの通知が窓内に出た割合
- **強到達** = 危険イベントのうち「強」tierが出た割合（分母は危険イベント数）
- **安全抑制** = 安全イベントで無発火だった割合
- **リード** = CPAから発火までの中央値（母数は到達したイベントのみ）
- **≥2.5s** = リードが2.5秒以上の割合（母数は同上）
