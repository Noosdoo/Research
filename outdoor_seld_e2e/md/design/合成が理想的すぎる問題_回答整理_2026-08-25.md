# 「合成データだけでは理想的すぎるのでは」への回答整理（2026-08-25）

> **位置づけ**: 本人の問い「合成で検出率99%とか出たけど、全部実録で検証しないと
> 理想的すぎる問題は解決しないのでは。でも全部実録は無理と知っている」への整理。
> **質疑・卒論の考察でそのまま使う**。数値はすべて確定評価セット（学習・検証に未使用の1,800クリップ）。

## 1. 「99%」の正体

`md/seminar/resume/README.md` の数値の出典表より:

- **検出率 97.2〜100%**（これが「99%」）
- 総合F値 91.3% / 方向誤差 中央値1〜5度 / 距離 至近5m以内で中央絶対誤差0.21m / 静音EV 98.99%

## 2. 「理想的すぎる」の裏付けは、すでに自分の手元にある

```
通知の至近到達率（同一採点器）
  未来の音も参照してよい場合   85.0%
  過去の音だけで判断する場合   73.0%（ft2・2026-08-20 再学習が正）
```

**判断材料を1つ現実に近づけただけで12ptの低下。**「合成が甘い」の直接証拠として使える。

## 3. なぜ合成だと高く出るか（正直な列挙）

| | 合成 | 実環境 |
| --- | --- | --- |
| 背景雑音 | **拡散性の有色雑音のみ**（`src/outdoor_seld/noise.py`） | 人の声・工事・風・建物反射 |
| 音源 | 同一波形＋周波数±3〜5%・時間構造±10%のジッタ（v8以降） | 個体差ははるかに大きい |
| 反射 | 地面の一次反射のみ | 建物・塀・路面材質 |
| ラベル | 音と**完全一致**（同一計算経路から出力） | 人が書いた1行メモ |
| マイク | **完全静止・無回転**（`scene.py:29,78-79`） | 歩けば回る |

とくに**人の声が1つも入っていない**。街で最もありふれた干渉音が未知のまま。

## 4. 「全部実録」では原理的に解けない（4点）

1. **学習データにならない**。録れるのは210本≒数時間。PSELDNetsは1,167時間。桁が3つ違う
2. **正解ラベルが作れない**。人が現場で書けるのは象限（90度幅）と横距離の目測1点だけ。
   度単位の方向も、時々刻々の距離も手入力しない設計（計画書 R7・step20_v2 の「未実装（意図的）」）
3. **危険な条件を作れない**。車の至近帯（≤1.5m）は安全上再現しない＝計画書 R2 に
   「車のcritical帯は倫理上未検証」と明記
4. **公開データが存在しない**。屋外・危険音・方向ラベル付きの実録は調査範囲でゼロ
   （`md/research/新規性サーベイ_2026-07.md`）

## 5. だから実録は「置き換え」ではなく「校正」に使う

```
合成で作る → 少数の実録で「どこがズレているか」を見つける → 合成側を直す → また測る
```

**ablationがその道具**。「どの物理を外すと実録の成績が落ちるか」＝実環境で本当に効いている物理の特定。

実録の3枠は、それぞれ別のズレを測っている:

| 枠 | 何のズレを見るか |
| --- | --- |
| ablation共通110本 | クラスごとに通知が成立するか |
| 歩行対比100本 | 装着して歩くことの影響（**原因分解はしない**＝R7） |
| 負例100分以上 | 実環境の雑音で誤警告が出るか ← **人の声にここで初めて当たる** |

## 6. 正直に言う限界

- 210本では「**桁違いに壊れていないか**」しか言えない（R3に事前登録済み。20〜30pt未満の差は「検出できず」）
- 車の至近帯は**倫理上未検証**
- 合成の97〜100%が実環境でいくつになるかは、**この規模では正確には出せない**

## 7. 質疑用の回答文

> 合成での検出率は97〜100%ですが、**合成が理想的すぎるからだと考えています**。実際、
> **過去の音だけで判断する条件にすると到達率が12ポイント落ちました**。
> 全部を実録でやるのは原理的に無理です。**公開データがなく、自分で録れる量は学習に足りず、
> 正解ラベルも人手では作れません**。なので実録は**置き換えではなく校正**に使います。
> 少数の実録で合成のどこがズレているかを特定して、合成側を直す。**ablationがその道具**です。
