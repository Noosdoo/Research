# 通知 v4.5「流れモード」— 事前宣言（2026-09-03 19:15・掃引前に固定）

本人判断（2026-09-03 13:24）「③ 流れモードを v2 の規則に入れる＝A」。v4.3 ＋ 警告音 hold の **後段**に足す 1 段で、
規則本体（強・中の判定、CPA 予測、方位帰属）には触れない。評価は長尺セット v1（`長尺セット_設計と事前宣言_2026-09-03.md` §4）。

## 1. 問題

幹線の歩道を歩くと、横 3〜4 m を通る車ごとに「中（注意）」が出て、1 分に何回も震える（本人「鳴らしすぎ」）。
v4.4（車の hold・交通量モード・不応期）は 10 秒の開発用 val では効果を測れず「採用なし」。長尺セットで測り直す。

## 2. 規則（候補の形。パラメータだけ掃引する）

- 側 = 方位の左右（az > 0 = 左）。デモ機器の Joy-con 左右と同じ粒度
- その側で **届けた「中」が W 秒以内に K 回**あったら、以後その側の「中」を**抑える**（届けない）
- 解除: その側で **強**が出た／**C 秒**その側で「中」が無かった
- **強・警告音（サイレン・クラクション・バック音・ベル・踏切）は抑えない**（安全側）
- 実装: `scripts/_long_score.py` の `flow_filter(eps, K, W, C)`（発火列への後段フィルタ）

## 3. 掃引（fold40・200 本）

| パラメータ | 候補 |
| --- | --- |
| K（回） | 2, 3 |
| W（秒） | 10, 20 |
| C（秒） | 10, 20 |

8 構成 ＋ 流れモードなし。指標は長尺セット宣言 §4（注意/分・抑えた中・害・至近の強到達・警告不変）。

## 4. 判断基準（先に固定）

- fold40 で **幹線の歩道の注意/分が −30% 以上** かつ **害（抑えた中のうち後で至近になった車の割合）≤ 2%**
  かつ **至近の強到達が流れモードなしから −1pt 以内** かつ **警告音の変化 0 件** の構成を候補にする
- 候補が複数なら、注意/分の減りが最大のもの（同率なら K・W・C が小さいもの）
- fold41 で同じ 4 条件を満たせば **採用**。満たさなければ **流れモードは v2 に入れない**（機器側の束ねだけ）で確定
- 至近の強到達は流れモードで変わらないはず（強を抑えないため）。変わったら実装の誤り → 掃引前に直す
