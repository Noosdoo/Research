# 警告音クラスの持続抑制（ホールド方式）設計 — 2026-08-24

> **踏切の前を歩いているだけで鳴り続けないか**」と指摘され、実装を確認したところ
> **5秒おきに再通知される**ことが判明した。本書はその修正設計。**未実装**。

## 1. 現状の規則（step12_notify_v9.py）

警告音5クラス（サイレン／クラクション／バック音／自転車ベル／踏切）:

```python
REFRACTORY = 50           # 5秒
DIR_REFRACT_DEG = 45.0    # 不応期は「クラス×方向」単位

def blocked(c, k, az):
    return any(k - kp < REFRACTORY                                  # 前回【発火】から5秒未満
               and abs((az - ap + 180) % 360 - 180) <= DIR_REFRACT_DEG
               for kp, ap in last_fires[c])                          # ← 発火時刻だけを記録
```

- 0.3秒（3フレーム）連続で検出したら発火
- `last_fires` には**発火した時刻だけ**が入る
- したがって**鳴り続けている音でも、5秒経てば不応期が切れて再発火する**

**踏切の前に30秒立つと、通知は最大6回。** 車には「頻発したら消音する交通量モード」があるが、
警告音クラスには同等の仕組みが無い。

## 2. 直し方（ホールド方式）

**「前回**発火**から5秒」を「前回**検出**から5秒」に変える。** これだけ。

```python
last_seen = defaultdict(list)   # class -> [(最後に検出したframe, az)]

# 検出があったフレームで毎回更新する（発火の有無に関わらず）
# blocked() は last_seen を見る
```

こうすると、鳴り続けている間は `last_seen` が更新され続けるので**不応期が切れません**。
検出が**5秒以上途切れてから再検出**されたときだけ、新しいイベントとして鳴ります。

### 言い換えると

**警告音クラスも、距離クラスと同じ「エピソード単位で1回」に揃える。**
距離クラス側は既に `group_episodes` → `_episodes_with_upgrade` でそうなっている。
エピソードの区切り幅だけが違う（距離クラスは連続フレーム、警告音は5秒の途切れ）。

## 3. なぜ1回でよいのか

**本研究は視覚が健常であることを前提にしている**（スライド3の「前提」）。
一度気づかせれば、以後は**目で確認できる**。踏切なら遮断機が見える。
持続している危険を繰り返し伝える必要は薄い。

## 4. 代償（正直に書く）

**最初の1回を見落としたら、次が来ない。** 振動を感じ損ねた場合の救済がなくなる。

折衷案として「**持続が30秒を超えたら1回だけ再通知**」を入れる手もあるが、
**30秒には根拠が無い**（設計値になる）。当面は入れず、限界として記録する。

## 5. 評価への影響

| 指標 | 影響 |
| --- | --- |
| 警告音の到達率 | **不変**（最初の発火は変わらない） |
| 誤警告率［回/時］ | **下がる**（重複発火が消える） |
| 通知回数 | **下がる** |

到達率が変わらないので、**これまでの数値を作り直す必要はない**。
ただし誤警告率を報告するときは、どちらの規則で測ったかを明記する。
