## 研究上の対応関係

音源・正解軌跡・検出結果・通知・緊急度は既存のファイルを使用します。街並みは表示用のモデルで、外観から音響反射や遮蔽を再計算する処理はありません。追加した生活道路・住宅・街路設備、信号や遮断棒の外観を、実験の正解ラベルや交通制御として扱わないでください。実地図の建物外観も写真から復元したものではなく、既存の配置図に合わせた手続き生成です。

同じ配置CSVはファイル名に依存しない乱数シードを使用するため、モデル版と参考版の外観が一致します。静的な部材はマテリアル別にメッシュへまとめ、場面の切替時にメッシュと移動物体用マテリアルを解放します。描画用の静的部材には物理コライダーを生成しません。

## 歩行位置と画面表示の修正

歩行者を車道まで含めていた車線の結合処理を修正。左右の車線が歩行者を挟む場合は、歩行経路をまたいで一つの車道にしません。場面1は元データの左右の車両位置を保つため、車道の間に分離した歩行通路を設けています。通常の片側道路の場面は道路の脇の歩道、至近接近の場面は段差のない路側帯、横断の場面は記録された進行線上の横断帯を使います。
