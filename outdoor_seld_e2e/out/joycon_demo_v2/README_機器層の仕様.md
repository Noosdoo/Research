# 機器層（提示）の仕様 — デモ＝実機の位置づけ（2026-09-05 本人決定）

Unity のデモ再生（`unity/JoyconDemoPlayer.cs`）を**実機の提示処理そのもの**として扱う。ここに書いた処理とパラメータが
「機器層」の正式な仕様で、検出層（モデル）・通知層（v4.3＋hold）の出力は一切変えずに受け取る。

```
検出層（モデル・因果推論）→ 通知層（v4.3＋hold: 強/中/警告 = cues.csv、緊急度 0..1 = urgency.csv）→ 機器層（この文書）→ 振動子 4 個
```

## 1. 入力

| ファイル | 中身 | 作る側 |
| --- | --- | --- |
| `<場面>_cues.csv` | 通知層の発火（時刻・段・クラス・方位）。4/4 確認つき。束ね無しの生の出力 | 通知層 |
| `<場面>_urgency.csv` | 毎フレーム（0.1 秒）の緊急度 0〜1 と方位。v4.3 と同じ最接近予測の式。確認なしの生の値 | 通知層 |
| `<場面>_detect.csv` / `_scene.csv` / `_layout.csv` | 検出層の出力・正解の位置・地図（画面表示用。振動には使わない） | 検出層／生成 |

## 2. 振動子の配置と方位→振動子（2026-09-06 00:03: **5 個**に確定＝完成イメージ図（8/27）・9/15 スライドの「振動子 5 個」と一致）

- **5 個・72° の均等刻み**（本人 00:13）: 前左 +36°・左 +108°・**後 180°**・右 −108°・前右 −36°（方位は DCASE 規約: 0°=前、+=左）。どの方位も一番近い振動子まで 36° 以内。
  資料の図は「前方 180°」だが、後ろから来る車が主な危険なので**後ろに 1 個**置く（左右 2 段＋後 1）
- 機器: **Joy-con 4 本 → 前左・前右・左・右、Wii リモコン 1 本 → 後**（暫定。Joy-con が 5 本そろったら Wii を外して差し替えるだけ）
  - Joy-con: HD 振動。強さ 0〜1 と周波数（低・高）を指定できる
  - Wii リモコン（`unity/WiiRemote.cs`）: 偏心モーターの ON/OFF だけ。**強さは周期 60 ms のうち ON にする割合で近似**（0.9 以上は常時 ON）、周波数は無視、100 ms 未満のパルスは 100 ms に伸ばす。
    強弱の表現が粗いので、強弱が効く前ではなく**後**に当てる
- 割当: Joy-con は **R キー**で「前左→前右→左→右」の順にボタンを押して決める（未割当は接続順: L1=前左 R1=前右 L2=左 R2=右）。
  Wii は 1 本目が「後」（2 本目は予備。W で切替）。**N キー**で Wii を再検索（あとから繋いだ本を拾う）。**T キー**で 5 個を順に震わせて確かめる（前左→前右→左→右→後）
- 足りない振動子は「未接続」（K の表示に出る）。接続数が 2 以下のときは左右按分（sin）に落とす
- S=左右入替（後はそのまま。確認用・既定 OFF）
- 履歴: 9/5 深夜に一度 6 個（左 3・右 3）で実装 → 9/6 00:03 に資料と機器に合わせて 5 個に確定（6 個版・4 個版のコードは `unity/archive/`）

## 3. 段階の通知（cues.csv・警告）

| 段 | パターン | 束ね（M・既定 ON） |
| --- | --- | --- |
| 強（至近） | 320/640 Hz・振幅 1.0・110 ms を 0.18 秒周期で 0.72 秒 | 同じ段の再発火が 1.0 秒以内なら新しい連打を出さず 0.45 秒延長。担当が別の振動子に移ったらそちらへ引き継ぐ |
| 中（注意） | 80/160 Hz・振幅 0.4・90 ms を 0.39 秒周期で 0.78 秒 | 同上 |
| 警告（警告音） | 120/240 Hz・振幅 0.5・300 ms 単発 | 束ねない |

連続モード（G・既定 ON）のときは 強・中 の段階振動は出さず、緊急度で連続に震える（警告は単発のまま）。担当の振動子は発火時の方位に一番近い役割。

## 4. 連続モード（urgency.csv・既定 ON＝本人採用 2026-09-03）

| 処理 | 仕様 | 理由 |
| --- | --- | --- |
| 無振動しきい値 | 緊急度 < 0.15 は無振動 | 安全域で震えない |
| **確認** | 直近 4 フレーム（0.4 秒）のうち 2 フレーム以上で緊急度 ≥ 0.15 のときだけ立ち上がる | 検出層が 1 フレームだけ出す緊急度（安全な車で 0.24 など）で震えない。段階の通知の 4/4 確認の軽い版（2026-09-05） |
| **保持** | 確認できた最後の値（緊急度・方位）を 0.3 秒保つ | 検出層の 1 フレーム抜けで振動が途切れない（2026-09-05） |
| **方位の安定化** | 受け入れ済みの方位から 60° 以上跳んだ方位は、**2 フレーム続いたときだけ**受け入れる。それまでは前の方位で震える。1 秒以上静かなら次は新規扱い | 全場面の突き合わせで前後・左右の取り違え 49 フレーム中 40 が 1 フレームの単発（2026-09-05） |
| **側の記憶** | 安定化後の方位が **+8° 以上を 2 フレーム**続けたら「左」、−8° 以下なら「右」に確定。確定後は反対側の 2 振動子を 0 にし、反対側の条件が満たされるまで変えない。未決定（真正面）は前の 2 つ。切替の合図・1 秒の無音・場面切替で未決定に戻す | 前から来る車が遠いうちは方位が真正面（1.2 m 横でも 30 m 先で 1.5°）なので前右も震えていた（2026-09-05 本人）。ヒステリシスでふらつきなく左右を確定。再生評価で反対側の振動子の時間 0.46 → 0.13 s/本 |
| 切替の合図（J・既定 ON） | 方位の跳びを受け入れたとき（＝追跡が別の車に乗り移った）、新しい側で 400/800 Hz・振幅 1.0・70 ms × 2（0.11 秒間隔）。合図の 0.25 秒は連続振動を止め、その後 0.6 秒かけて 0.3→1.0 に立ち上げ直す | 「別の車が来た」と伝える |
| 強さ | 振幅 = 0.25 + 0.75 × 緊急度（注意の入口 0.25〜至近 1.0）、周波数 低 80→320 Hz・高 160→640 Hz を緊急度で補間 | 近づくほど強く・高く |
| **方向按分（P・既定 ON）** | 接続している振動子の角度 θk に対し 重み = cos⁴(方位 − θk)（負は 0）、側の記憶で反対側を 0、正規化して振幅 × 1.6、0.08 未満は出さない。5 個（72° 刻み）では真正面 0° は前左・前右が半々、36° で前左だけ、真後ろ 180° は後だけ、144° は左と後が半々。側の記憶は後を 0 にしない。2 個以下のときは sin で左右按分 | 左 8° で前右 0.39、左 15° で 0.16、真正面は前 2 個とも（cos² → cos⁴ 2026-09-05） |
