# 【仮ablation】確認runの再採点結果（2026-08-17）— **卒論・発表には使わない**

> ## これは「仮」です
>
> 2026-08-15〜16 に実施した **確認run** の予測を、2026-08-17 の自己監査で見つけた
> 採点欠陥を直したうえで採点し直したもの。**本番のablationではありません。**
>
> - **数値を卒論・発表に使わない。** 各arm 1本ずつ・ゼミ後に土俵が変わる可能性がある
> - 使ってよいのは **順位・傾向・「差が検出できること」の実証** まで
> - 本番はゼミ後にFableが、土俵を修正して §9 の事前登録に沿って実施する

## 直したこと（元の採点の欠陥）

1. **tier再現率の分母が「検出できたフレーム」だけだった。** 検出失敗が分母から消え、
   armごとに検出率が違うため比較が成立していなかった → **絶対到達率**を追加
2. **事前登録§8.6の「区間端±0.3s除外」が未実施だった** → `--edge-frames 3` で実施
3. **事前登録§9.3の主要評価はΔSELDスコアなのに、tier再現率で代用していた**
   → `scripts/_abl_seld_score.py` を新設してSELDスコアを算出

## 結果③ 区間端除外（±0.3s）の影響：**重大・注意tierには無し**

| tier | 除外なし | 除外あり |

手続き上の瑕疵だが、主指標への影響はゼロ）。

## 指標によって結論が変わる点（卒論では両方報告すべき）

| arm | SELDスコア | 重大tier到達率 |
| --- | --- | --- |
| no_doppler | −0.0007（**差なし**） | −3.0pt（**差あり**） |

**ドップラーは検出・方向（SELD）には効かないが、距離推定には効く。**
音の周波数変化＝接近の速さの手がかりなので、距離側にだけ効くのは物理的に筋が通る。
