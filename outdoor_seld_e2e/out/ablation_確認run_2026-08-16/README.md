## 要点（詳細は §5-bis）

ラン揺れフロア **約1pt** に対し、重大tier再現率の変化:

**no_ground −10.9pt ＞ no_1r −8.1pt ＞ no_doppler −3.3pt ≫ no_airabs −0.4pt（差なし）**

効き目は **地面反射 ＞ 幾何減衰 ＞ ドップラー ≫ 大気吸収**。
事前登録では no_ground は「むしろ改善」と予想していたため、**最大の劣化は予想外**。
