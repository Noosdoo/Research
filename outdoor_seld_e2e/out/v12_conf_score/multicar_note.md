# 同一クラス多重（複数車）の現在地（2026-08-12測定・conf確定評価セット）

- 車の可聴フレーム在存検出率: 1台 99.22% (n=43,719) / 2台 98.99% (n=23,984) /
  3台以上 99.32% (n=13,089) → 台数によらずフラット（v10.2のデータ追加で解消済み）
- 同時2台以上が可聴の30,746フレーム: 1台以上検出 99.92% / 2台以上の同時分離 77.74%
  → 存在の見逃しはほぼ無いが、多重度の完全分離は残る粒度課題（B2帰属問題と同根）

## なぜフラットにできたか（機構、2026-08-12追記）

1. 器は元から多重対応: multi-ACCDOAは同一クラスに3トラックの席を持つ（能力不足ではない）
2. 真因は共起例題の欠如: v10.2で複数車シーン（トラック分離ラベル付き）を追加→
   ADPIT（順列不変損失）が席の対応付けを自動で解く=同一クラス多重のための損失設計。
   均衡対照（量だけ揃え共起なし）で改善しないことから「量でなく共起例題」と確定
3. 物理: 在存検出は台数増で総エネルギー増=難しくならない。分離の手がかりは方向
   （FOAの強度ベクトル）で、方位の違う2台は信号として区別可能
4. 77.7%の裏面も同機構: 方位が統合閾値(15°)内に重なる瞬間は音響的に分離が
   原理的に困難→トラック融合。「方向が手がかり」の表裏
